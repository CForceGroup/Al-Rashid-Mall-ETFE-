# Al-Rashid Mall ETFE Dome

## ETFE Dome Structure at Al-Rashid Mall

C.Force Group delivered an innovative ETFE dome structure at Al-Rashid Mall in Al Khobar, combining advanced architectural design with lightweight and high-performance ETFE technology.

The project features a multi-layer ETFE cushion system designed to provide natural daylight, visual appeal, and effective protection while maintaining a lightweight structural solution.

### Project Highlights
- ETFE cushion dome structure
- Customized printed ETFE film
- Lightweight architectural solution
- Natural daylight transmission
- Innovative multi-layer system
